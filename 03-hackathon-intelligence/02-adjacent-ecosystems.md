## Cross-Ecosystem Signal for GenLayer
- Strong startups solve **payments/verifiability/ERP integration** with **receipts + staking/slashing + policy-as-ENS + bridge**, not one-shot juries. Exactly the missing pieces in most GenLayer demos (verified in 01-genlayer-ecosystem).
- Distribution via existing rails (x402 165M payments $50M total, $0.3 avg, Coinbase/Cloudflare/Google x402 Foundation) is decisive; GenLayer docs push x402 but only AgentEscrow + Internet Court bridge implement it — white space.
