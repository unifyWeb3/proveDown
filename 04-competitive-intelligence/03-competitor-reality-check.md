## 2. Materially Changes Thesis? — No, But Sharpens Wedge

**Threats that would have forced pivot (but don't):**

- If Pingoru at $15 already delivered *functional quality* (fill/match) not just status page, our quality wedge would be dupe — it doesn't.
- If ArcSLA already had **DisputeModule for subjective** live, our LLM jury would be late — it's **future not live** (docs say optional, planned). So still whitespace.
- If Verifiable-SLAs TEE+ZK already covered LLM-judged quality + on-chain anchoring at scale 1M/hour, our jury would be less efficient — but it only covers deterministic SLO aggregation (threshold check) not LLM subjective, and needs TEE enclave per SLA (heavier).

**What actually changes (sharpening, not pivot):**

1. **Wedge wording must be `functional SLO attestation` not `status page uptime attestation`.** Pingoru + Datadog Updog already dominate objective uptime for $0-15. Our Tom vs Jerry is quality (filter: 80% fill where 15s empty still 200) — that's where LLM + jury adds beyond ping + status page. This matches technical validation: latency variance huge → jury can't do precise p95 anyway — must judge quality via bundle.
2. **Target on-chain native (x402/Arc) first.** ArcSLA live with 9 providers on Arc shows deterministic marketplace exists and buyers *are* on-chain. For them, GenLayer adds *subjective extension* via LLM jury (their missing DisputeModule). For pure Web2 with stripe billing, on-chain adds less vs Pingoru $15. So go where on-chain settlement already exists.
3. **Deterministic deadline vs quality are complementary, not competing.** ArcSLA could *call* ProveDown as its DisputeModule: Arc handles per-call stake/slash deterministic, ProveDown handles disputed quality via jury when provider says "I responded in time, here's receipt hash" but caller says "response was garbage (empty fill)". That's partnership not competition — position as extension.
4. **TEE+ZK vs Jury tradeoff explicit:** TEE+ZK (Verifiable-SLAs) gives hardware attestation + privacy + constant-time proof for *objective* metrics (latency, response code) at 1M/hour. Jury gives *subjective* judgment (does this enrichment count?) with diverse LLMs + appeal doubling, no hardware manufacturer trust but needs stake/bond. They can coexist: TEE collects telemetry authentically, jury judges quality bundle. Could hybrid later.

**Update to `02-emerging-competitors.md`:** Append this table and the 4 sharpenings. Mark ArcSLA, Pulse, TrustTrace, Verifiable-SLAs, Pingoru, Updog.ai as **High relevance, not counted before**.

**Decision:** **Preserve thesis, but narrow positioning per Task 3 wedge challenge + this scan:** ProveDown is *functional quality SLO* attestation for agent pipelines (fill/match/error) + error-budget attribution, with on-chain bridge for x402-native marketplaces, sidecar on top of Pingoru/Datadog not replacement, and subjective extension to ArcSLA's deterministic core.

No pivot to procurement — procurement's Web2 competitors are Xelix/Medius etc. (already in 01), not threatened by these SLA competitors.
